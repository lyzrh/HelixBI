## 七、诚实性声明

- **实测**：LLM 调用次数；prompt 输入 token（真实 tokenizer 计数）；确定性阶段耗时（墙钟）；意图快路径覆盖与准确率；重放率 / 兜底率 / False Replay（来自真实路由）
- **建模**：LLM 输出内容与 output token（桩）；LLM 与沙箱耗时（线性投影）
- **未采集**：真实 provider 计费；真实沙箱执行耗时（需 Docker）
